# Additional technology marks

These SVG marks are stored locally and used as project stack icons. Names and logos belong to their respective owners.

- **Logfire**: Pydantic, [official plugin asset](https://github.com/pydantic/skills/blob/main/plugins/logfire/assets/logfire-icon.svg). Geometry preserved; accessibility attributes are supplied by the badge.
- **OpenTelemetry**: [CNCF artwork, color icon](https://github.com/cncf/artwork/blob/main/projects/opentelemetry/icon/color/opentelemetry-icon-color.svg). Geometry and colors preserved.
- **OAuth**: Chris Messina, [OAuth project source](https://github.com/aaronpk/oauth.net/blob/main/public/images/oauth-logo.svg), [original attribution and license](https://wiki.oauth.net/w/page/12238520/Logo). Licensed under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Unused embedded font, hidden variant and pattern removed; visible artwork preserved. File: oauth2.svg.
- **PDF.js**: Mozilla, [official project logo](https://mozilla.github.io/pdf.js/images/logo.svg). A viewBox matching the original 64 by 64 canvas was added for scaling; artwork preserved.
- **LibreOffice**: The Document Foundation, [official website SVG](https://www.libreoffice.org/media/libreoffice-tdf-logo.svg). Document symbol extracted from the logo lockup with its original paths and a tight viewBox. See [branding guidelines](https://wiki.documentfoundation.org/Marketing/Branding).
- **Docker**: Docker, [official website](https://www.docker.com/) header SVG. Whale mark preserved, with the official site's blue color variant (#1d63ed) set explicitly for rendering as an image.
